# Variables and Bindings
## compiled into Python

- Python has no immutable variables
- no type hints

```decl
let name = "Alice"
let value: int = 1234
var counter = 0
var Sp = 0:u16
actor = 'Bob'
```
```py
# let variables become regular Python variables
name = "Alice"
value = 1234

# var variables (mutable)
counter = 0
Sp = 0
```
