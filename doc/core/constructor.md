# `init`
## constructor = initializer

```decl
class bebebe {
  bebebe(n:int) -> Self { value=n }
  init(f:float) -> bebebe { value=n }
  bebebe(s:str) { value=s }
}
```

- return type can be omitted means return the `Self` = same class type
- for constructors fixed `init` name can be used in place of class name
