# Для кого ?

- Для системных программистов, которые устали от segfault'ов.
- Для разработчиков приложений, которым нужна производительность C++, но с современными инструментами и экосистемой.
- Для программистов на Python или JS, которые хотят создавать очень быстрые модули для своих проектов.
- Для всех, кто хочет писать надежный, поддерживаемый и быстрый код.
