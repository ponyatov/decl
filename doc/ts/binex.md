# [[decl/core/binex]]
## compile [[decl/decl|decl]]'s [[decl/core/binex|binex]]es to [[TypeScript]]

- **`bitsyntax`** [](https://jspm-packages.deno.dev/package/bitsyntax@0.1.0)[](https://explore.market.dev/ecosystems/javascript/projects/bitsyntax-js)[](https://www.skypack.dev/view/bitsyntax) — Эта библиотека — **прямая реализация Erlang-синтаксиса** для Node.js. Позволяет использовать строки-паттерны, например: `'len:8/integer, str:len/binary'` [](https://jspm-packages.deno.dev/package/bitsyntax@0.1.0)[](https://www.skypack.dev/view/bitsyntax).
    
- **`@aho/binpat` (Binpat)** [](https://jsr.io/@aho/binpat@0.1.1)[](https://jsr.io/@aho/binpat/0.1.1/README.md) — Более современная TypeScript-библиотека. Предлагает **декларативный** и **типобезопасный** подход, где структура данных описывается объектом с помощью встроенных парсеров (`u8`, `string`, `array`) [](https://jsr.io/@aho/binpat@0.1.1)[](https://jsr.io/@aho/binpat/0.1.1/README.md).
    
- **`@vicimpa/data-pack`** [](https://www.npmjs.com/package/@vicimpa/data-pack?activeTab=dependencies) — Если ваша цель — не просто парсинг, а эффективная (де)сериализация данных (бинарный RPC), эта библиотека предоставляет **схемы** для упаковки данных в бинарный формат.
