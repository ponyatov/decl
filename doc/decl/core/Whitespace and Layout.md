# Whitespace and Layout

- **minimize syntax noise**:
	- no `{}` hell:
		- `{}` used specially for lambda-like code blocks
		- syntax blocks uses tab-indented syntax
	- **tab-indented syntax** used for forcing more code readability
		- most IDE and code editors supports Python-like code shifting with `Ctrl-[`, `Ctrl-]` or similar hotkeys
		- no `tab` chars, only spaces
	- paren-less calls:
		- no `()` in function/method calls
		- `()` used only for expression grouping
- `;` used for code splitting in single-line code snippets
