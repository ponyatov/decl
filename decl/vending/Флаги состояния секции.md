# Флаги состояния секции

- публикуются в общий топиках `States/Sections/#`
- также деляться на две подгруппы: 
	- `/Spiral/#`
	- `/Postomat/#`

## состояния

- `Section_Spiral_State` Спиральная секция
	- OK
		- секция функционирует в штатном режиме
	- BLOCKED
		-  секция недоступна
- `Section_Postomat_State` Постоматная секция
	- OK
		- секция функционирует в штатном режиме
	- BLOCKED
		-  секция недоступна
