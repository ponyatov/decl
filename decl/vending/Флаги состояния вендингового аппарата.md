# Флаги состояния вендингового аппарата
## [[Спецификация интерфейса вендингового аппарата#States]]

В зону ответственности АСУ НУ входит отслеживания состояния системы и установления соответствующих флагов для его мониторинга. Флаги располагаются в древовидной структуре топиков MQTT (по умолчанию с префиксом `Machine/`), которые напрямую отражают структуру объекта состояний `state`.

## Взаимодействие

| Топик (Topic)                            | Описание    |
| :--------------------------------------- | :-----------|
| `Machine/Command`      | Команду от ВУ к НУ.           |
| `Machine/Response`     | Ответ от НУ к ВУ.             |
| `Machine/QR`           | Считанный QR от НУ к ВУ.      |
| `Machine/RFID`         | Считанный RFID от НУ к ВУ.    |

| `Machine/States/InputVoltage` | OK<br>ERR_HIGH<br>ERR_LOW | Входное напряжение в норме<br>Входное напряжение повышено<br>Входное напряжение понижено | - <br>Выдать предупреждение о повышенном напряжении<br>Выдать предупреждение о пониженном напряжении | -<br>-<br>-

## Флаги состояния шин

Флаги состояния шин публикуются внутри `Buses/{ИндексШины}/#` (индекс от 0) и имеют следующие значения:

| Топик (Topic) | Значения | Расшифровка | Действия | Комментарий |
| :------------ | :------- | :---------- | :------- | :---------- |
| `Machine/States/Buses/{Index}/Voltage` | OK<br>ERR_HIGH<br>ERR_LOW | Напряжение на шине в норме<br>Напряжение на шине повышено<br>Напряжение на шине понижено             | - <br>Выдать предупреждение о повышенном напряжении<br>Выдать предупреждение о низком напряжении |
| `Machine/States/Buses/{Index}/Current` | OK<br>ERR_HIGH            | Ток на шине в норме<br>Ток на шине повышен                                                           | - <br>Выдать предупреждение оп повышенном токе                                                         |
| `Machine/States/Buses/{Index}/Temp`    | OK<br>ERR_HIGH<br>ERR_LOW | Температура на ИП шины в норме<br>Температура на ИП шины повышена<br>Температура на ИП шины понижена | - <br>Выдать предупреждение о повышенной температуре<br>Выдать предупреждение о пониженной температуре |

## Флаги состояния секции

Общие флаги состояния секций публикуются в топиках `Machine/States/Sections/{ИмяСекции}/#`. Имя секции задается при конфигурации (например, `spiral`, `postomat`).

| Топик (Topic) | Значения  | Расшифровка | Действия | Комментарий |
| :------------ | :-------- | :---------- | :------- | :---------- |
| `Machine/States/Sections/{ИмяСекции}/IsAvailble` | YES<br>NO | Секция функционирует в штатном режиме<br>Секция недоступна | - <br>Топик несёт справочный характер, причины недоступности необходимо смотреть по статусам ячеек и портов данной секции |
| `Machine/States/Sections/{ИмяСекции}/Running`    | YES<br>NO | Секция занимается выдачей ТМЦ<br>Секция простаивает        | Откладываем выполнения новой BI до завершения текущей<br>Можно выполнять новую BI                                         |

## Флаги состояния строк и столбцов

| Топик (Topic)                                      | Значения      | Расшифровка                                                         | Действия                                                                                                                  |
| :------------------------------------------------- | :------------ | :------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------ |
| `Machine/States/Sections/{ИмяСекции}/Rows/{Index}` | OK<br>BLOCKED | Строка секции функционирует в штатном режиме<br>Строка недоступна   | - <br>Топик несёт справочный характер, причины недоступности необходимо смотреть по статусам ячеек и портов данной секции |
| `Machine/States/Sections/{ИмяСекции}/Cols/{Index}` | OK<br>BLOCKED | Столбец секции функционирует в штатном режиме<br>Столбец недоступен | - <br>Топик несёт справочный характер, причины недоступности необходимо смотреть по статусам ячеек и портов данной секции |

## Глобальная конфигурация
> `Config/Global`

Ветка `Config/` формируется НУ на основе конфигурации хранимой в НУ. 

| Топик (Topic)                                    | Тип / Структура | Описание                                                          |
| :----------------------------------------------- | :-------------- | :---------------------------------------------------------------- |
| `Machine/Config/Global/Buses/{Index}/Number`     | `number`        | Порядковый номер шины.                                            |
| `Machine/Config/Global/Buses/{Index}/VoutChName` | `string`        | Имя канала для считывания напряжения.                             |
| `Machine/Config/Global/Buses/{Index}/IoutChName` | `string`        | Имя канала для считывания тока.                                   |
| `Machine/Config/Global/Env/{Index}/Name`         | `string`        | Название датчика окружающей среды (например, TempSensor).         |
| `Machine/Config/Global/Env/{Index}/ChName`       | `string`        | Имя физического канала датчика.                                   |
| `Machine/Config/Global/Net/{Ключ}`               | `string`        | Различные сетевые параметры (WAN_IP, MQTT_IP, REDIS_PORT и т.д.). |

## Конфигурация секций
> `Machine/Config/Sections`

Конфигурация каждой секции представляет собой массив объектов со следующими параметрами:

| Топик (Topic)                            | Тип / Структура | Описание                                                               |
| :--------------------------------------- | :-------------- | :--------------------------------------------------------------------- |
| `Machine/Config/Sections/{Index}/Name`   | `string`        | Уникальное имя секции (например, `spiral`, `postomat`).                |
| `Machine/Config/Sections/{Index}/Id`     | `string`       | Идентификатор секции.                                    |
| `Machine/Config/Sections/{Index}/IOList` | `string[]`      | Массив имен модулей ввода-вывода (IO), закрепленных за данной секцией. |
