# Global_Machine_States
## [[Глобальные флаги состояния]]

- `Global_Machine_States`
	- `OK`
		- Аппарат работает в стандартном режиме
	- `SERVICE`
		- Аппарат находится в сервисном режиме
		- Никакие бизнес команды выполнятся не должны
	- `DEPLOY`
		- Обновление прошивки
		- Никакие бизнес команды выполнятся не должны
