## Transaction

- **запрос на выдачу ТМЦ от ВУ**
- топик: [[Спецификация интерфейса вендингового аппарата#Command|Command]]
- передаётся список ячеек на выдачу

схема запроса:

- Transaction
	- ID : GUID         // уникальный идентификатор транзакции
	- Timestamp : ts    // метка времени
	- UserID : string   // уникальный идентификатор конечного пользователя аппарата
	- Source = "HiLvl"  // идентификатор верхнего уровня
	- Orders
		- Target
			- id : GUID               // идентификатор аппарата
			- name : string	          // имя аппарата
		- Command : enum [[#Command]]
		- Cells[]

## Response

- **ответы от НУ по статусам обработки [[#Transaction]]-запроса**
- топик: [[Спецификация интерфейса вендингового аппарата#Response|Response]]
- ответ приходит отдельным сообщением для каждой ячейки

## Command

Предлагаемые команды:

- [[GetItem]] – запрос на выдачу ТМЦ из указанных ячеек;

Не реализовано:

- GetAll – выдача ТМЦ, открытие всех ячеек (массив Cells в данном случае не учитывается);
- SetItem – загрузка ТМЦ в указанные ячейки (только для постоматной секции)
- SetAll – загрузка ТМЦ во все ячейки по загруженной конфигурации;
- GetStatus – получение статуса аппарата;
- Reboot – перезагрузка аппарата;
- SetConfig – загрузка конфигурационного файла;
- Maintenance – перевод аппарата в режим обслуживания.

## сообщения НУ -> ВУ

Для генерации сообщений с устройств нижнего уровня предлагается использовать такую-же конструкцию транзакции, например:
```json
{
	"Transaction": {
		"ID": "36fa-aabc-012d",					 // уникальный идентификатор транзакции
		"Timestamp": "Fri, 02 Feb 1996 11:17:55",// время выполнения транзакции
		"User": {	},							 // пользователь пуст
        "Source": "Lo-level - {RFID | QR}",         // Источник сообщения - RFID
		"Target": {								 // аппарат, которому предоставляется данная транзакция
			"id": 0,							 // идентификатор аппарата
			"name": "Top level",				 // имя объекта назначения
			"type": "top level control",		 // тип объекта - управление на верхнем уровне
			"article": "12qw-5577-a7f8"			 // артикул аппарата
		},
		"Order": { { "type", "barcode" } },		 // Информация со считывателя			
	}
}
```

- [[Спецификация интерфейса вендингового аппарата#`Command`]]
- [[Спецификация интерфейса вендингового аппарата#Response]]

В рамках запуска MVP структура топиков была сведена к следующей:
`Machine/Sections` - хранит объект { spiral: { id, name }, postomat: { id, name } }. id, name используются в транзакциях согласно шаблону
`Machine/Command` - топик в который ВУ пишет команду
`Machine/Response` - топик в который НУ пишет ответы
`Machine/QR` - топик в который НУ пишет ввод от периферии
`Machine/RFID` - топик в который НУ пишет ввод от периферии
