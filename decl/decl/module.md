# module
# `decl` component for adding custom features

## code generation

- `decl/cpp/` embedded C++
- `decl/js/`  JavaScript target

## microcontollers

- `decl/mcu/` microcontollers (common parts)
  - `decl/avr/` ATmetga AVR8
  - `decl/arm/` ARM SoCs & Cortex-M
  - `decl/esp/` ESP32*

## Linux (host, embedded and custom build)

- `decl/linux/`

## networking

- `decl/net/`

## databases

- `decl/db/`
  - `redis`
  - `mongo`
