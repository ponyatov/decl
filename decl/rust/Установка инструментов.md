# Установка инструментов

## [[rustup]]

rustup — это менеджер установки и версий Rust. Он позволяет легко переключаться между стабильной, ночной (nightly) и любыми версиями компилятора.

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
which rustup
```
```
/home/user/.cargo/bin/rustup
```

```
echo 'source "$HOME/.cargo/env"' | tee -a ~/.bashrc
```

> Компилятор [[rustc]] и пакетный менеджер [[cargo]] последней стабильной версии установятся автоматически
