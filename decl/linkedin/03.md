# va-script calculator rewrite in `decl`

reference: https://medium.com/@vrakitine/vaop-in-examples-reactjs-mini-va-calculator-75fde22feb83

target: single page `src/calculator.html`
- mixes CSS/HTML/browser JS
- no any frameworks used

![[decl/core/gui]]

```decl
// use single form as a top-level GUI widget
glob gui = form {
	title = 'VA‑Calculator | decl reimplemented'
	theme = dark
	
	calculator {
		align: topdown
		size: 240x320px     // fixed size for LCD emulation
		background: #222
		align: left
		
		// numerical display
		display:lcd {
			align: right // on most calculators numbers extends to left
		}
		
		// dumps state machine transitions
		state:textline {
			align: left
			color: orange
		}
		
		keypad:button[5x5] {
			align: center
			  
			[ ac:AC   on:OFF   sqrt:'√'   perc:'%'   mc:'MC' ]
			[   7       8        9         div:'/'   mx:'M'  ]
			[   4       5        6         mul:'*'   mm:'M-' ]
			[   1       2        3         sub:'-'   mp:'M+' ]
			[   0    dot:'.'   neg:'/-/'   add:'+'   eq:'='  ]
		]
		
	}
}

style lcd {
	background: #142; color: yellow; fontsize:5mm
}
```

- on every click any button will send its id as message:
```decl
class button {
	click: calculator!self.id  // send button id on click
}
```

The logic of calculator splitted from GUI as singleton actor:

```decl
glob calculator = actor {
	X:float       // X register
	M:float       // M register
	on:bool=false // on/off state

	// any X change must trigger gui.display update
	X.set = gui.calculator.display.set X
	
	// display can be powered on/off to indicate on state
	on.set = if on gui.calculator.display.on
	         else  gui.calculator.display.off
	
	// message processing rules
	init: self!ac                       // on program start reset
	ac:   on=true; X=0                  // power on and reset registers
	off:  on=false                      // triggers display
	sqrt: X=sqrt(X)                     // negative error see next
	
}
```
