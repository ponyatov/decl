# MQTT Components

- [[srvMQTTClient]] - MQTT client
- [[srvMQTTGateway]] - MQTT gateway
- [[srvProxyMQTTClient]] - MQTT client proxy
- [[srvProxyMQTTGateway]] - MQTT gateway proxy

```decl
module HorizonServer {
    mqtt {
        srvMQTTClient           // MQTT client
        srvMQTTGateway          // MQTT gateway
        srvProxyMQTTClient      // MQTT client proxy
        srvProxyMQTTGateway     // MQTT gateway proxy
    }
}
```
